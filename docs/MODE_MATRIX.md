# Mode matrix

| Topic | Static | Declarative | Open-ended | Mixed |
|---|---|---|---|---|
| A2UI | Fixed surface | Agent-specified catalog tree | Rich generated surface | Fixed shell + generated surface slot |
| AG-UI | Fixed app responding to events | Events carry typed UI intents | Events coordinate agent-proposed UI | Fixed event reducer + generated content |
| MCP Apps | Fixed tool view | Tool returns validated view data | Tool-linked interactive view | Fixed host chrome + tool-generated panel |
| JSON-render | Hand-authored JSON tree | Schema-validated tree | Agent chooses tree within catalog | App-owned shell + generated subtree |
| OpenUI | Fixed OpenUI source | Parsed constrained source | Streamed language-generated view | Fixed actions + generated layout |
| Harness | Fixed workflow | Declarative task plan | Agent chooses presentation | Fixed safety loop + open presentation slot |

Use this table while teaching: **static/declarative/open-ended/mixed describe UX authority**, not four competing protocols.
