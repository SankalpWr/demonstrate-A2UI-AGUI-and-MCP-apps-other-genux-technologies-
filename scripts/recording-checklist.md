# Recording checklist

- Install Node 20+ and run `npm test` and `npm run lint`.
- Start with `npm start`.
- Open `http://localhost:8787`.
- Record one 3–5 minute segment per topic using `docs/YOUTUBE_SCRIPTS.md`.
- For each topic show all four modes and the right-side payload.
- Do not show `.env`, tokens, private URLs, or personal data.
- After upload, add each YouTube URL to the submission README.
